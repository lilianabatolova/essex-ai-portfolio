Reflection Model

My Learning Cycle

1. Learn

Engage with module materials, seminars, academic literature, practical coding exercises, and AI concepts.

2. Apply

Convert theory into portfolio artefacts, assignments, experiments, code snippets, diagrams, and professional use cases.

3. Reflect

Analyse what worked, what was difficult, what feedback was received, and which assumptions need to be challenged.

4. Improve

Define concrete actions for the next module, assignment, project, or professional AI Factory activity.
