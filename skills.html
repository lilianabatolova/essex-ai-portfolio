Review Cycle

How This Matrix Will Be Maintained

This skills matrix will be reviewed at the end of each MSc module.

Each review will consider:

  • new academic and technical evidence;
  • feedback from tutors and peers;
  • completed practical artefacts;
  • changes in confidence and independence;
  • development actions completed;
  • new priorities for the following module.

Ratings will only be increased where there is clear evidence of development.
