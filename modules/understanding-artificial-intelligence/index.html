MODULE OVERVIEW

From AI Concepts to Learning Systems

This module develops the foundations required to understand Artificial Intelligence beyond its business applications. It progresses from core AI concepts and intelligent systems into machine learning, deep learning, feature engineering, supervised and unsupervised learning, model evaluation, and practical AI solution development.

AI Foundations

Understanding Artificial Intelligence concepts, intelligent systems, learning approaches, and the development of AI as a discipline.

Machine Learning

Developing an understanding of supervised and unsupervised learning, model training, algorithms, and the role of data in learning systems.

Practical Development

Building familiarity with Python, Jupyter Notebook, Scikit-learn, PyTorch, data preparation, experimentation, and model evaluation.

LEARNING JOURNEY

Key Learning Themes

Rather than documenting every unit separately, the learning journey is organised around the major capabilities developed throughout the module.

FOUNDATIONS

Understanding AI Systems

Exploring what constitutes an Artificial Intelligence system, how learning systems differ from conventional software, and how different AI approaches are selected for different types of problems.

LEARNING APPROACHES

Machine Learning & Deep Learning

Developing an understanding of supervised and unsupervised learning, machine learning algorithms, deep learning concepts, model training, and the importance of data.

DATA

Feature Engineering & Representation

Understanding how data is selected, transformed, represented, and prepared so that learning algorithms can identify meaningful patterns.

SUPERVISED LEARNING

Classification & Regression

Applying structured approaches such as CRISP-DM to explore data and understand how supervised learning solutions are developed for prediction and classification problems.

UNSUPERVISED LEARNING

Clustering

Exploring how learning systems can identify patterns and groups within data without predefined target labels, including the practical development of clustering solutions.

EVALUATION

Model Performance

Examining model evaluation approaches including validation strategies, accuracy, precision, recall, F1 score, sensitivity, specificity, and the importance of selecting metrics appropriate to the problem.

TECHNICAL DEVELOPMENT

Building Practical AI Capability

A major development goal within this module is moving from conceptual familiarity with AI toward greater confidence with the technical processes behind machine learning systems.

Python

Continued development of Python fundamentals including lists, strings, functions, data handling, and computational problem solving.

Jupyter Notebook

Using notebook-based workflows to explore datasets, execute machine learning experiments, document analysis, and interpret results.

Scikit-learn & PyTorch

Building familiarity with machine learning and deep learning frameworks used to prepare data, train models, and evaluate learning systems.

PROFESSIONAL APPLICATION

Connecting Technical Learning with Enterprise AI

The value of the module extends beyond developing technical knowledge. It provides a stronger foundation for making informed decisions about AI systems in professional practice.

AI Use Case Validation

A deeper understanding of learning approaches improves the ability to challenge whether a proposed AI method is appropriate for the underlying business problem.

Model Evaluation

Understanding evaluation metrics strengthens discussions around model quality, acceptance criteria, trade-offs, and readiness for operational use.

Responsible AI

Technical understanding supports stronger judgement around data quality, bias, explainability, governance, and the responsible deployment of AI systems.

REFLECTION

Developing Technical Confidence

Learning Reflection

Moving from managing AI delivery to understanding the systems being delivered

My professional experience has given me strong exposure to AI delivery, operating models, governance, and organisational adoption. This module is helping me build the technical layer underneath that experience.
