Selected Technical Evidence

Code Development

Python Implementation

The Python version used concise syntax to normalise names, remove duplicates, and sort the cleaned values. 

names = ["Anna", "anna", "BOB", "Bob"]

normalised_names = [name.lower() for name in names]
unique_names = sorted(set(normalised_names))

print(unique_names)

Output: duplicate values with different capitalisation are consolidated into one consistent result.

JavaScript Implementation

The JavaScript version applied the same logic using array mapping, a Set, and sorting. 

const names = ["Anna", "anna", "BOB", "Bob"];

const normalisedNames = names.map(
  name => name.toLowerCase()
);

const uniqueNames = [...new Set(normalisedNames)].sort();

console.log(uniqueNames);

Learning point: the two languages can produce equivalent outcomes while differing in syntax, structure, and readability.

These examples are concise reconstructions of the programming concept and are included as portfolio evidence. They do not reproduce copyrighted module materials or assessment briefs.

Critical Reflection

What I Learned

Code That Works Is Not Enough

At the beginning of the module, I approached programming mainly as the task of producing a correct result.

I now recognise that professional software must also be understandable, maintainable, testable, secure, and appropriate for its users and context.

Small Decisions Can Have Wider Effects

Converting names to lowercase appeared to be a minor code change, but it demonstrated how inconsistent data can influence processing quality and later outcomes.

This is directly relevant to Artificial Intelligence, where data-cleaning choices can affect training, predictions, fairness, and trust.

Technical and Ethical Quality Are Connected

Readability and documentation are not only stylistic preferences. They support accountability, peer review, error detection, knowledge transfer, and responsible maintenance.

My Leadership Perspective Is an Advantage

I am not studying to become a traditional software engineer. My goal is to combine enough technical depth with governance, delivery, and organisational judgement to lead Artificial Intelligence responsibly.
